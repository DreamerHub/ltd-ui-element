# 组件预览 Playground

在线交互式组件预览工具，实时调整属性并查看效果。

<Playground />

---

## 使用说明

1. **选择组件**：从顶部下拉菜单选择要预览的组件
2. **调整属性**：在右侧面板中修改各项属性，左侧预览区实时更新
3. **查看代码**：点击底部「代码」区域展开，可复制生成的组件代码到项目中使用

## 支持的组件

| 组件     | 说明                                   |
| -------- | -------------------------------------- |
| Button   | 基础按钮，支持类型、尺寸、状态等属性   |
| TablePro | 高级表格，支持分页、选择、操作列等功能 |

> 随着组件库扩展，Playground 将同步支持更多组件。
